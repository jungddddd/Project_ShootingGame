# 기말과제_울라프 슈팅게임

## 자바 GUI를 활용하여 만들어본 겨울왕국 배경의 슈팅게임


## 조작법

방향키로 이동 가능


커맨드로 점프 가능


스페이스바로 공격 가능


적 1명 제거 당 100점 획득


총 500점 이상 획득 시, 보스전 시작


---


## 스테이지 별 기준

1번째 스테이지의 목표 : 제한된 총알로 적 처치하기
30개 탄 안에 2000점을 채우면 게임 화면이 멈추고, C를 누르면 다음 스테이지로 넘어간다
이전 스테이지 보다 적의 이동속도 4초 빠르게 설정 + 방해물 추가
보상 : 탄을 적게 사용한만큼 점수 배율 증가

2번째 스테이지의 목표 : 특정 적 우선처치
새로운 적을 등장시켜 해당 적은 필수적으로 모두 처치해야 다음 스테이지로 넘어간다.
2가지 종류의 적 중, 초록괴물은 fireball을 맞춰도 죽지않음. 무조건 피해야하는 설정 추가

3번째 스테이지의 목표 : 제한시간(3분) 안에 보스처치
5000점을 넘으면 마지막 보스 등장
-> 보스의 경우, 체력게이지 창을 추가해 체력이 줄어드는 것을 가시적으로 보여줌
-> 게임 난이도 상승을 위해 공격 종류 2가지로 구현. 플레이어를 향한 3갈래탄 발사 추가.
-> 보스는 위/아래로도 움직이게 추가 구현
-> 3분 내에 보스를 처치하지 않으면 보스가 분노 상태로 변해 공격력이 두 배가 됩니다.
보상 : 시간을 절약한만큼의 점수 배율 증가

보스는 HP가 0이 되면 지속적으로 폭발하면서 화면 아래로 밀려 내려가 사라질 것.
파괴된 보스로부터 대량의 아이템이 드롭 될 것.
esc 누르면 게임 일시정지
